请直接在这台电脑生成并打开我的「深夜开发者」个人 AI 用量报告，然后把本地报告路径发给我。
使用已有的 Python 3.9+ 和终端。以下程序包来自项目的公开站点，先下载到临时目录，再核对 SHA-256，匹配才执行。无需 pip、管理员权限、后台服务或手动导入 JSON。日志和报告都留在本机。若没有可用的 Python 或本机读取权限，请说明具体原因。
请用已有 Python 实际运行以下代码（无图形界面时追加 --no-open 并返回可取回的本地报告文件夹）。如下载遭遇新版本导致的校验失败，请让我刷新网页重新复制指令。

import hashlib, pathlib, subprocess, sys, tempfile, urllib.request
url = "https://mantank.github.io/midnight-token-ledger/personal-report.pyz"
with tempfile.TemporaryDirectory() as tmp:
    target = pathlib.Path(tmp) / "personal-report.pyz"
    with urllib.request.urlopen(url, timeout=45) as response:
        data = response.read(2_000_001)
    if hashlib.sha256(data).hexdigest() != "c7b3834360ea4e61e33ef0d565da6a1181d34b3021a7634de8d6fe5631ffcf68":
        raise ValueError("报告生成器校验失败，请刷新网页重新复制指令")
    target.write_bytes(data)
    subprocess.run([sys.executable, "-I", str(target)], check=True)
